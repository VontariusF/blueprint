# vontariusf/blueprint

Research the problem. Define the solution. Give the build agent a blueprint.

Created by [Vontarius Falls](https://vontarius.xyz). [Overview and examples](https://vontarius.xyz/skills/blueprint/).

## Install

Requires Node.js 22.20 or later for the Skills CLI:

```sh
npx skills add vontariusf/blueprint --skill blueprint
```

The installer lets you choose your coding agent. Add `-g` for use across projects. Inspect the files and [UI reference credits](assets/ui-library/CREDITS.md) before installation.

## Use

Tell your agent: “Use Blueprint with the startup profile. Here is the problem I want to solve…”

Profiles: default, hackathon, startup. These are selectable planning presets, not separate native slash commands. Some hosts expose the local skill as `$blueprint`.

## What it produces

A project entry point linking the purpose, research, complete vision, scope, resources, user journeys, UI/UX mockups, critical path, decisions and observable completion criteria. Scope and artifacts adapt to the project and available tools. Missing access blocks dependent execution, not independent design work.

## Reusable context

Supply your own designated resource inventory and style preferences. The included example is a schema, not live access. Project decisions stay local unless you designate them for reuse. No personal credentials, paths or infrastructure are included.
